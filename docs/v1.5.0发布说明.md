# 抽奖姬 v1.5.0

开发者：想吃金丝虾球

- 新增安装版 GitHub 正式版本检查、下载及确认后安装更新。
- 新增“关于 / 更新”：仓库二维码、GitHub、Issue、PR 入口。
- 新增主界面与直播小窗名单自动上下滚动，可分别关闭。
- 新增运行异常提示和诊断信息导出。
- 新增独立启动检查工具，核对文件缺失、改变或无法读取，辅助排查 ICU 等启动错误。

推荐下载 `luckdraw-Setup-1.5.0-x64.exe`。1.4.x 用户需要先手动安装本版本，之后才可使用内置更新。免安装用户下载完整 ZIP 并全部解压，不要只复制 EXE。

安装更新会退出程序，本轮名单不会保留，请先保存需要的结果。登录信息和背景保存在个人应用数据目录，不随发行包分发。
