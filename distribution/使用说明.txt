抽奖姬 2.2.2 — Windows x64 安装版 / 免安装版

运行要求：Windows 10/11 64 位、可访问哔哩哔哩的网络和自己的 B 站账号。
无需安装 Node.js、Python 或开发工具。

1. 将 ZIP 全部解压到可写文件夹，不要在压缩包内运行。
2. 双击 抽奖姬.exe。保留同目录的 resources、locales、DLL 等文件。
3. 点击“登录 B 站”，在应用打开的官方网页自行登录。主界面显示昵称后即可设置。
4. 填写直播间号、参与互动词，选择所有观众或需佩戴本房间粉丝牌。
5. 点击“开始收集”，连接成功后显示“正在获取弹幕”，自动打开竖向直播小窗。
6. 点击主界面“抽取”或小窗“抽取一位”，自动暂停收集并显示中奖者。
7. 主界面和小窗的“开始收集”：首次开启收集；再次点击会将上一轮存入历史，清空当前名单并开启下一轮。未抽奖和零参与者的轮次也会保存。
8. “暂停收集 / 继续收集”：保留本轮参与名单、中奖结果、权重和礼物金额；继续时沿用本轮条件，只接收继续之后的新弹幕。暂停时可修改下一轮条件，点击开始才应用。

小窗可拖动、缩放、切换置顶；关闭后可在主界面重新打开，名单不丢失。
小窗中奖者固定显示在操作按钮下方；待抽名单可独立滚动。
状态：正在连接弹幕 / 正在获取弹幕 / 弹幕收集暂停。抽奖、停止、断开时均暂停。
可选择本地照片替换背景，也可恢复默认；照片保存在个人应用数据目录。背景支持调整压暗程度。
蓝色按钮开始、玫红按钮停止、金色按钮抽奖、紫色按钮打开直播小窗，均有独立图标。

规则：弹幕包含互动词即匹配；UID 去重；本房间粉丝牌按所属主播 UID 校验。
中奖者从候选池移除，本轮不会重复中奖；开启下一轮后可重新参与。只收集开始后的弹幕，不补录历史弹幕。
实时弹幕保留最近 2000 条，参与名单不因此丢失。主界面和小窗共享同一份抽奖名单。
登录使用应用自己的会话，与其他浏览器独立。登录数据保存于当前 Windows 用户的应用数据目录，不在分发包中。
程序没有代码签名证书，Windows 可能显示未知发布者。

连接失败时检查网络，点击继续收集保留当前名单并重连；点击开始收集则归档并开启新一轮。
登录失效时，在应用网页重新登录并刷新状态。没有参与者时检查房间号、互动词、粉丝牌条件。
分发请发送整个 ZIP，不要只发 EXE，也不要打包个人应用数据目录。
许可证：项目 MIT，参见 LICENSE-project.txt；Electron/Chromium 许可证随包提供。

排队与名单管理
- 抽奖 / 排队：在本轮设置顶部切换；暂停后可选择下一轮模式，点击开始收集后生效。
- 排队按本程序收到符合关键词、粉丝牌条件的弹幕顺序入列，UID 去重，不读取历史弹幕。
- 等待人数上限默认 20，可设 1–10000；开始后可调整，不能小于当前等待人数。
- 满员时新报名不入列，也不预留名额；出现空位后，新观众需再次发送关键词。
- 名单右侧移除按钮可在主界面和小窗使用。移除后空出名额，剩余人员顺序不变。
- 被移除者本轮不能再次加入，开启下一轮后可参加；同样适用于抽奖待抽名单。
- 抽奖名单的滑杆图标数字为权重，默认 1。点击可设 1–10000、最多两位小数，只在主界面显示和修改。
- 每次中奖概率 = 本人的权重 / 当前剩余参与者总权重。多人抽取时逐个抽取，中奖者移出，不重复中奖。
- 小窗标题栏增加“最小化”，不会暂停收集或清空名单；主界面“显示直播小窗”可恢复。
- 排队与抽奖共用当前一轮，切换模式需开启新一轮，不同时开启两种模式。

更新、关于与故障排查
- 推荐使用 Setup 安装版；安装版自动检查 GitHub 正式版本，点击下载并确认后安装，收集期间不能安装。ZIP 版手动下载。
- 关于 / 更新中显示仓库二维码、开发者、Issue 与 PR 入口，并支持导出诊断信息。
- 主界面和小窗名单支持自动上下滚动，开关独立保存；边缘停留两秒，手动操作后暂停五秒。
- 完全打不开时，双击同目录“启动检查.cmd”核对完整性并生成报告。重点检查 icudtl.dat 缺失或损坏，不要只传 EXE。
- 仓库：https://github.com/csudmj/bili-danmaku-lottery

房间号：首次启动房间号留空，自动记住上次输入，支持粘贴完整直播链接提取房间号；手动删空房间号后下次仍为空。不会自动收集弹幕。

权重与队列调整：
主界面“权重设置”可设舰长、提督、总督、普通本房间粉丝、其他观众五档权重，默认均为 1。专属权重名单填写 UID 时精确匹配；UID 留空时所有完整同名观众共用该权重。UID 规则优先于昵称规则，名单保存在本机。新入选时生效，也可明确应用到全部待抽者。全部恢复为 1 不删除专属名单；清空专属名单不改当前已入选权重。
队列可拖动左侧手柄或使用上下箭头调整，小窗同步。拖动中暂停自动滚动；新报名不会丢失。

V2.2.0 新功能
- 左侧选择“B站直播”；“B站视频”支持本人投稿弹幕和公开视频评论抽奖。
- 抽奖设置中可开启未中奖补偿，默认关闭，增量默认 0.1。一次点击抽奖算一次，无论抽几人；剩余待抽者增加后按 UID 保存至专属权重名单。中奖者的 UID 规则和同名共享规则自动删除。
- 权重范围 1–10000，最多两位小数。补偿后最高 10000；关闭不会自动恢复已有权重。
- 参与者权重不同时显示下一位中奖概率，相同时不显示。该数字不是一次抽多人至少中奖一次的概率。
- 排队设置中可开启礼物金额排序，默认关闭。仅开启期间、入队后收到的付费礼物累计；同金额按入队时间。免费礼物、入队前礼物、上舰和醒目留言不计入。
- 开启时每人旁边显示本轮金额，不能手动插队。关闭后金额隐藏、队列恢复入队顺序，可手动拖动。开启下一轮后金额归零。
- 礼物金额是服务器事件标称金额，不是折扣后实际支付额；断线和暂停期间无法补回漏掉的礼物。


V2.2.0 新增：
